ติดตั้ง MySQL

ทำพร้อมกันทั้งห้องตามจารย์ ใช้ตัวติดตั้งที่จารย์เตรียมไว้ ห้ามกดข้ามหน้าจอที่ยังไม่ได้อ่าน

1

ติดตั้งโปรแกรม

เปิดไฟล์ MySQL Community Server 8.4 แบบ MSI กด Next ตามปกติ เลือกแบบ Typical เมื่อติดตั้งเสร็จจะมีโปรแกรม MySQL Configurator เปิดขึ้นมาให้ตั้งค่าต่อ

2

ตั้งค่าใน MySQL Configurator

หน้า Type and Networking เลือก Config Type เป็น Development Computer และใช้ Port 3306 ตามเดิม

หน้า Accounts and Roles ตั้งรหัสผ่านของ root เป็นค่าที่จารย์บอก ทุกเครื่องใช้ค่าเดียวกัน จดไว้ให้ดี ลืมแล้วแก้ยาก

หน้า Windows Service ให้ติ๊ก Configure MySQL Server as a Windows Service และ Start the MySQL Server at System Startup จดชื่อ Service ไว้ด้วย (ปกติคือ MySQL84) แล้วกด Next จนถึงหน้า Execute ให้กด Execute แล้วรอจนเครื่องหมายถูกขึ้นครบ

3

ให้ terminal รู้จักคำสั่ง mysql

กดปุ่ม Windows พิมพ์ environment เลือก Edit the system environment variables กด Environment Variables ในกล่อง System variables เลือก Path กด Edit แล้วกด New ใส่

C:\Program Files\MySQL\MySQL Server 8.4\bin

กด OK ปิดทุกหน้าต่าง แล้วปิด terminal เดิมทั้งหมด เปิด terminal ใหม่ ถ้าไม่เปิดใหม่ เครื่องจะยังไม่รู้จักคำสั่ง

mysql --version
4

เข้า MySQL ครั้งแรก

mysql -u root -p --default-character-set=utf8mb4

ใส่รหัสผ่าน ตอนพิมพ์จะไม่เห็นตัวอักษรขึ้น เป็นเรื่องปกติ พิมพ์ให้ครบแล้วกด Enter

ผ่านเมื่อ mysql --version ได้เลขเวอร์ชัน และเข้าได้จนเห็น mysql> รอรับคำสั่ง

ส่วนที่ 2 (20 นาที)

ฐานข้อมูล ตาราง และชนิดข้อมูล

ภาพรวม

MySQL Serverมีหลายฐานข้อมูลมีหลายตารางมีหลายแถว

MySQL เป็นโปรแกรมที่รันอยู่เบื้องหลังตลอดเวลา ระบบหนึ่งระบบใช้ฐานข้อมูลหนึ่งก้อน เช่น evaluation ข้างในแยกเป็นตาราง ตารางหนึ่งเหมือนแผ่นงาน Excel ที่กำหนดชนิดข้อมูลของแต่ละคอลัมน์ไว้ตายตัว ข้อมูลอยู่ในเครื่องจนกว่าจะสั่งลบ ปิดโปรแกรมหรือปิดเครื่องก็ไม่หาย

ชนิดข้อมูลที่ใช้ในระบบประเมิน

ชนิดเก็บอะไรตัวอย่างในระบบ
INTจำนวนเต็มid, คะแนน 1–4, น้ำหนักตัวชี้วัด
VARCHAR(n)ข้อความสั้น ยาวไม่เกิน n ตัวชื่อ-สกุล, แผนก, ชื่อผู้ใช้
TEXTข้อความยาวความคิดเห็นของกรรมการ, รายละเอียดผลงาน
DECIMAL(5,2)ทศนิยมแบบแม่นยำคะแนนรวม เช่น 87.50
DATEวันที่วันเริ่มและวันสิ้นสุดรอบประเมิน
DATETIMEวันที่และเวลาเวลาที่ส่งผลประเมิน

ข้อกำหนดของคอลัมน์

PRIMARY KEY คือคอลัมน์ที่ใช้ระบุแถวแบบไม่ซ้ำกัน ส่วนใหญ่คือ id AUTO_INCREMENT ให้ฐานข้อมูลนับเลข id ให้เอง NOT NULL คือห้ามว่าง และ DEFAULT คือค่าที่ใส่ให้เองถ้าไม่ได้ส่งมา

ทุกคำสั่ง SQL ต้องจบด้วย ; ถ้าลืม MySQL จะขึ้น -> รอให้พิมพ์ต่อ พิมพ์ ; แล้ว Enter ก็ได้

ฝึก SQL

ทำต่อใน mysql> พิมพ์ทีละชุด ดูผลทุกครั้ง ช่วงนี้แนะนำให้พิมพ์เอง ไม่ต้องคัดลอก จะจำได้ดีกว่า

แก้และลบ ในตารางทิ้ง

สร้างตารางทิ้งไว้ฝึก จะได้ไม่ทำข้อมูลจริงพัง

CREATE TABLE practice_trash (
  id INT AUTO_INCREMENT PRIMARY KEY,
  note VARCHAR(50)
);
INSERT INTO practice_trash (note) VALUES ('ก'), ('ข'), ('ค');

UPDATE practice_trash SET note = 'แก้แล้ว' WHERE id = 2;
DELETE FROM practice_trash WHERE id = 3;
SELECT * FROM practice_trash;

ทีนี้ลองลืม WHERE ดูว่าเกิดอะไร

UPDATE practice_trash SET note = 'หายหมด';
SELECT * FROM practice_trash;
DROP TABLE practice_trash;

ผ่านเมื่อ อธิบายได้ว่าทำไมทุกแถวกลายเป็น หายหมด และสัญญากับตัวเองว่าจะเขียน WHERE ก่อนเสมอ

โจทย์ทำเอง: ตารางตัวชี้วัด

สร้างตาราง indicators มีคอลัมน์ id (เลขอัตโนมัติ), title (ข้อความไม่เกิน 200 ตัว ห้ามว่าง) และ weight (จำนวนเต็ม ห้ามว่าง) แล้วใส่ข้อมูล 5 แถว จากนั้นเขียน SQL ตอบโจทย์ทีละข้อ

ข้อ 1 แสดงเฉพาะตัวชี้วัดที่น้ำหนักมากกว่า 10 เรียงจากน้ำหนักมากไปน้อย ข้อ 2 เปลี่ยนน้ำหนักของตัวชี้วัด id 3 เป็น 15 ข้อ 3 ลบตัวชี้วัด id 5 แล้วแสดงที่เหลือทั้งหมด

เฉลย เปิดหลังทำเสร็จแล้วเท่านั้น 
CREATE TABLE indicators (
  id INT AUTO_INCREMENT PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  weight INT NOT NULL
);

SELECT * FROM indicators WHERE weight > 10 ORDER BY weight DESC;
UPDATE indicators SET weight = 15 WHERE id = 3;
DELETE FROM indicators WHERE id = 5;
SELECT * FROM indicators;

ต่อ Express เข้ากับ MySQL

Thunder Clientส่งExpressเรียกผ่าน mysql2MySQLตอบกลับทางเดิม

Express ไม่เก็บข้อมูลเองแล้ว แค่ส่งคำสั่ง SQL ที่ฝึกมาเมื่อกี้ไปให้ MySQL แล้วรอผล การรอผลจึงต้องใช้ async หน้าฟังก์ชัน และ await หน้าคำสั่งที่ต้องรอ ถ้าลืม await จะได้ของที่ยังไม่เสร็จกลับมาแทนข้อมูล

1

ติดตั้งตัวเชื่อมต่อ และสร้าง db.js

ในโฟลเดอร์โปรเจกต์ Express

npm install mysql2

สร้างไฟล์ db.js ไว้ข้างไฟล์เซิร์ฟเวอร์

const mysql = require('mysql2/promise');

const pool = mysql.createPool({

  database: 'evaluation'
});

module.exports = pool;

ในไฟล์เซิร์ฟเวอร์ เพิ่มบรรทัดนี้ใต้ const app = express(); แล้วลบ let evaluatees = [...] กับ let nextId ทิ้ง

const pool = require('./db');

ผ่านเมื่อ รันเซิร์ฟเวอร์ได้โดยไม่มี error และ /health ยังใช้ได้

2

เปลี่ยน Route ให้ใช้ SQL

แทนที่ Route ของ /evaluatees ทั้งสามตัวด้วยชุดนี้ โครงเหมือนเมื่อวาน เปลี่ยนแค่ตรงกลางเป็นคำสั่ง SQL ที่เพิ่งฝึก

app.get('/evaluatees', async (req, res) => {
  try {
    const [rows] = await pool.query('SELECT * FROM evaluatees');
    res.json(rows);
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

app.get('/evaluatees/:id', async (req, res) => {
  try {
    const [rows] = await pool.query(
      'SELECT * FROM evaluatees WHERE id = ?',
      [req.params.id]
    );
    if (rows.length === 0) {
      return res.status(404).json({ message: 'ไม่พบผู้รับการประเมิน' });
    }
    res.json(rows[0]);
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

app.post('/evaluatees', async (req, res) => {
  try {
    const { name, department } = req.body;
    const [result] = await pool.query(
      'INSERT INTO evaluatees (name, department) VALUES (?, ?)',
      [name, department]
    );
    res.status(201).json({ id: result.insertId, name, department });
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

เครื่องหมาย ? คือช่องว่างที่ mysql2 จะเติมค่าจาก Array ให้อย่างปลอดภัย ห้ามเอาค่าที่ผู้ใช้ส่งมาต่อเป็นข้อความ SQL เอง

ผ่านเมื่อ POST คนใหม่ได้ 201 แล้วหยุดเซิร์ฟเวอร์ รันใหม่ GET ด้วย id นั้นยังเจอ เปิด MySQL ดูด้วย SELECT ก็เห็นคนใหม่ และ GET id 999 ได้ 404

ใครเสร็จก่อน

ท้าทายเพิ่ม ถ้า POST มาโดยไม่มี title ให้ตอบ 400 ก่อนส่งคำสั่งไปฐานข้อมูล

คำใบ้ชั้นที่ 2

กดปุ่ม Windows พิมพ์ services เปิดโปรแกรม Services หาชื่อ MySQL84 ถ้าสถานะไม่ใช่ Running ให้คลิกขวาแล้วเลือก Start

ขึ้น Access denied for user 'root'

รหัสผ่านผิด พิมพ์ใหม่ช้า ๆ ระวังปุ่ม Caps Lock และภาษาของแป้นพิมพ์ว่าเป็นภาษาอังกฤษ

MySQL ขึ้น -> หรือ '> ค้างอยู่

-> คือลืม ; พิมพ์ ; แล้ว Enter ส่วน '> คือเปิดเครื่องหมาย ' ไว้แต่ไม่ได้ปิด พิมพ์ \c แล้ว Enter เพื่อยกเลิกคำสั่งนั้นแล้วพิมพ์ใหม่

ภาษาไทยในตารางเป็นเครื่องหมายคำถาม

ตอนเข้า MySQL ลืมใส่ --default-character-set=utf8mb4 ให้ออกด้วย exit แล้วเข้าใหม่พร้อมตัวเลือกนี้ จากนั้นลบแถวที่เพี้ยนแล้วใส่ใหม่ ข้อมูลที่ POST ผ่าน Express จะไม่มีปัญหานี้

ตอนต่อ Express

Error ขึ้นว่า ECONNREFUSED

Express ต่อ MySQL ไม่ติด ลองเข้า MySQL จาก terminal ดูว่ายังเข้าได้ไหม ถ้าไม่ได้ ดูคำใบ้เรื่อง Services ข้างบน

Error ขึ้นว่า ER_ACCESS_DENIED_ERROR

รหัสผ่านใน db.js ตรงกับรหัสที่ใช้เข้า MySQL หรือเปล่า

Error ขึ้นว่าไม่มีฐานข้อมูลหรือไม่มีตาราง

ชื่อ database ใน db.js สะกดตรงกับที่สร้างไว้ไหม

คำใบ้ชั้นที่ 2

เข้า MySQL พิมพ์ USE evaluation; แล้ว SHOW TABLES; ถ้าไม่เห็นตาราง ให้กลับไปทำส่วนที่ 3 ขั้นที่ 2 ใหม่

ได้ข้อมูลแปลก ๆ หรือ rows เป็น undefined

ดูว่ามี await หน้า pool.query หรือยัง และ Route มี async ข้างหน้าหรือเปล่า

คำใบ้ชั้นที่ 2

pool.query ส่งกลับมาเป็น Array สองช่อง ช่องแรกคือข้อมูล จึงต้องเขียน const [rows] = มีวงเล็บเหลี่ยม

ทายผลก่อนกดส่ง

ตอบในใจก่อน แล้วค่อยลองบนเครื่องตัวเองว่าตรงไหม

Exit Ticket

คู่ A ตรวจคู่ B แล้วสลับกัน ผู้ตรวจเป็นคนลงมือเองบนเครื่องของเจ้าของงาน ตรวจจากผลที่รันจริงเท่านั้น
