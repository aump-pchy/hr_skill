เกม: คำสั่งนี้อยู่ที่ไหน

ห้ามเปิดไฟล์เมื่อวานดู แต่ละบรรทัดเลือกว่าเราพิมพ์มันที่ไหน แล้วกดตรวจ

วันนี้จะมีที่ที่สี่เพิ่มเข้ามา คือโค้ด Vue ที่รันในเบราว์เซอร์ของผู้ใช้

เรื่องใหม่วันนี้

เส้นทางของข้อมูลเมื่อมีหน้าเว็บ

Vue ในเบราว์เซอร์fetchExpressSQLMySQLตอบกลับทางเดิม แล้ว Vue วาดตารางใหม่

Vue ไม่ได้คุยกับฐานข้อมูลตรง ๆ ทุกอย่างต้องผ่าน API ของเรา

ref คือตัวแปรที่หน้าเว็บคอยดู

ข้อมูลที่ประกาศด้วย ref() เมื่อเปลี่ยนค่า หน้าเว็บจะวาดใหม่ให้เอง ในส่วน <script> ต้องอ่านเขียนผ่าน .value แต่ในส่วน <template> ใช้ชื่อตรง ๆ ได้เลย

v-for, v-model และ @submit

v-for วนสร้างแถวตามข้อมูลใน Array v-model ผูกช่องกรอกกับตัวแปร พิมพ์เมื่อไหร่ตัวแปรเปลี่ยนตาม ส่วน @submit.prevent คือเรียกฟังก์ชันตอนกดส่งฟอร์ม โดยไม่ให้เบราว์เซอร์รีเฟรชหน้า

CORS

หน้าเว็บ Vue รันที่ port 5173 ส่วน API อยู่ที่ 3000 เบราว์เซอร์ถือว่าเป็นคนละเว็บ และจะไม่ยอมให้เรียกข้ามกัน จนกว่า API จะบอกว่าอนุญาต Thunder Client ไม่ใช่เบราว์เซอร์จึงไม่เคยเจอเรื่องนี้

ทำตามทีละขั้น

ทำเสร็จหนึ่งขั้น ตรวจให้ผ่านก่อนแล้วค่อยไปขั้นถัดไป เปิด terminal ไว้สองหน้าต่าง หน้าต่างหนึ่งรัน Express อีกหน้าต่างรัน Vue

1

ให้ Express อนุญาตหน้าเว็บ

ในโฟลเดอร์ Express ติดตั้ง

npm install cors

ในไฟล์เซิร์ฟเวอร์ เพิ่มสองบรรทัดนี้ไว้ก่อน app.use(express.json());

const cors = require('cors');
app.use(cors());

ผ่านเมื่อ รัน Express ใหม่แล้ว GET /evaluatees ใน Thunder Client ยังได้ข้อมูลเหมือนเดิม

2

สร้างโปรเจกต์ Vue

ไปที่โฟลเดอร์นอกสุด ที่เดียวกับที่มีโฟลเดอร์ Express แล้วรัน

npm create vue@latest frontend

คำถามทั้งหมดตอบ No ไปก่อน วันนี้ยังไม่ใช้ Router จากนั้น

cd frontend
npm install
npm run dev

ผ่านเมื่อ เปิด http://localhost:5173 แล้วเห็นหน้าตัวอย่างของ Vue

3

เก็บที่อยู่ API ไว้ที่เดียว

สร้างไฟล์ .env ในโฟลเดอร์ frontend ใส่บรรทัดนี้

VITE_API_URL=http://localhost:3000

หยุด npm run dev ด้วย Ctrl+C แล้วรันใหม่ ทุกครั้งที่แก้ .env ต้องรันใหม่ วันขึ้นเครื่องแม่ข่ายจะแก้แค่บรรทัดนี้บรรทัดเดียว

ผ่านเมื่อ รัน Vue ใหม่ได้โดยไม่มี error

4

แสดงรายชื่อจาก API

เปิด frontend/src/App.vue ลบของเดิมทั้งหมด แล้ววางชุดนี้

<script setup>
import { ref, onMounted } from 'vue'

const API = import.meta.env.VITE_API_URL
const evaluatees = ref([])
const errorMsg = ref('')

async function loadEvaluatees() {
  errorMsg.value = ''
  try {
    const res = await fetch(`${API}/evaluatees`)
    if (!res.ok) throw new Error('โหลดข้อมูลไม่สำเร็จ')
    evaluatees.value = await res.json()
  } catch (err) {
    errorMsg.value = 'ติดต่อเซิร์ฟเวอร์ไม่ได้: ' + err.message
  }
}

onMounted(loadEvaluatees)
</script>

<template>
  <main>
    <h1>รายชื่อผู้รับการประเมิน</h1>
    <p v-if="errorMsg" style="color: red">{{ errorMsg }}</p>
    <table border="1" cellpadding="6">
      <thead>
        <tr><th>ลำดับ</th><th>ชื่อ</th><th>แผนก</th></tr>
      </thead>
      <tbody>
        <tr v-for="e in evaluatees" :key="e.id">
          <td>{{ e.id }}</td>
          <td>{{ e.name }}</td>
          <td>{{ e.department }}</td>
        </tr>
      </tbody>
    </table>
  </main>
</template>

ถ้าหน้าตาเพี้ยนเพราะสไตล์ตัวอย่างของ Vue ให้ลบบรรทัด import './assets/main.css' ใน src/main.js วันนี้เน้นให้ทำงานได้ก่อน ความสวยค่อยว่ากันทีหลัง

ผ่านเมื่อ หน้าเว็บเห็นรายชื่อทุกคนที่อยู่ในฐานข้อมูล ตรงกับ GET /evaluatees ใน Thunder Client

5

ฟอร์มเพิ่มคนใหม่

ในส่วน <script setup> เพิ่มต่อจาก loadEvaluatees

const form = ref({ name: '', department: '' })

async function addEvaluatee() {
  errorMsg.value = ''
  try {
    const res = await fetch(`${API}/evaluatees`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(form.value)
    })
    if (!res.ok) throw new Error('เพิ่มข้อมูลไม่สำเร็จ')
    form.value = { name: '', department: '' }
    await loadEvaluatees()
  } catch (err) {
    errorMsg.value = err.message
  }
}

ในส่วน <template> วางฟอร์มนี้ไว้ใต้ <h1>

<form @submit.prevent="addEvaluatee">
  <input v-model="form.name" placeholder="ชื่อ-สกุล" required>
  <input v-model="form.department" placeholder="แผนก">
  <button type="submit">เพิ่ม</button>
</form>

ผ่านเมื่อ กรอกแล้วกดเพิ่ม ตารางมีคนใหม่ทันที ช่องกรอกว่างลง และรีเฟรชหน้าแล้วคนใหม่ยังอยู่

ติดตรงไหน เปิดคำใบ้ทีละชั้น

หน้าเว็บไม่มีข้อมูล ใน Console ขึ้นคำว่า CORS

API ยังไม่อนุญาตให้หน้าเว็บที่ port 5173 เรียก ดูขั้นที่ 1 อีกครั้ง

คำใบ้ชั้นที่ 2

app.use(cors()) ต้องอยู่ก่อน Route ทั้งหมด และต้องหยุดแล้วรัน Express ใหม่หลังแก้

หน้าเว็บขาวทั้งหน้า

กด F12 เปิด Console แล้วอ่านข้อความสีแดงบรรทัดแรก ส่วนใหญ่บอกเลยว่าพิมพ์ผิดตรงไหนใน App.vue

คำใบ้ชั้นที่ 2

เช็กว่าแท็ก <script setup> และ <template> เปิดปิดครบคู่ และ import สะกดถูก

Error ขึ้นว่าเรียก undefined/evaluatees

Vue ยังอ่าน .env ไม่ได้

คำใบ้ชั้นที่ 2

ไฟล์ .env ต้องอยู่ในโฟลเดอร์ frontend ไม่ใช่ใน src ชื่อตัวแปรต้องขึ้นต้นด้วย VITE_ และต้องรัน npm run dev ใหม่หลังแก้

กดเพิ่มแล้วหน้ารีเฟรช ข้อมูลไม่เข้า

ดูว่าเขียน @submit.prevent ครบหรือยัง ถ้าไม่มี .prevent เบราว์เซอร์จะส่งฟอร์มแบบเก่าแล้วรีเฟรชหน้า

กดเพิ่มแล้วได้ข้อความ เพิ่มข้อมูลไม่สำเร็จ

เปิด F12 ไปแท็บ Network กดเพิ่มอีกครั้ง แล้วคลิกที่ request ที่เป็นสีแดง ดูว่าได้ status อะไร

คำใบ้ชั้นที่ 2

ถ้าได้ 500 ให้ดู terminal ของ Express ว่า error อะไร ถ้า body ที่ส่งไปว่าง ให้เช็ก headers กับ JSON.stringify

รัน npm run dev แล้วบอกว่าหา script ไม่เจอ

อยู่ผิดโฟลเดอร์ ต้อง cd frontend ก่อน

โจทย์ทำเอง: หน้าตัวชี้วัด

ทำหน้าตัวชี้วัดในไฟล์ App.vue เดิม ต่อจากตารางรายชื่อ ปิดโค้ดตัวอย่างไว้ เปิดดูได้เมื่อติดเกิน 10 นาทีเท่านั้น

ต้องมีตารางแสดงตัวชี้วัดทั้งหมดจาก GET /indicators และฟอร์มเพิ่มตัวชี้วัดที่มีช่อง title กับ weight ส่งไป POST /indicators เพิ่มแล้วตารางต้องอัปเดตทันที

ช่อง weight ให้ใช้ type="number" และ v-model.number เพื่อให้ส่งไปเป็นตัวเลข ไม่ใช่ข้อความ

ท้าทายเพิ่ม ถ้าเมื่อวานทำให้ API ตอบ 400 ตอนไม่มี title ได้แล้ว ให้เอา required ออกจากช่องกรอกชั่วคราว แล้วทำให้หน้าเว็บแสดงข้อความที่ API ส่งกลับมา แทนข้อความกลาง ๆ

ติดเกิน 10 นาที ถามคู่ซ้อมก่อน คู่ซ้อมช่วยชี้ได้ แต่ห้ามพิมพ์แทน ถ้ายังไม่ออกค่อยเรียกจารย์

ทายผลก่อนกดส่ง

ตอบในใจก่อน แล้วค่อยลองบนเครื่องตัวเองว่าตรงไหม

Exit Ticket
