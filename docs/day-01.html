เกม: เรียงเซิร์ฟเวอร์ของเมื่อวาน

ห้ามเปิด VS Code ดู แตะบรรทัดทางซ้ายเพื่อวางต่อท้ายโปรแกรมทางขวา แตะบรรทัดทางขวาเพื่อเอาคืน เรียงเสร็จแล้วกดตรวจ

บรรทัดที่สลับไว้
โปรแกรมของฉัน

เรียงถูกแล้ว เปิด VS Code พิมพ์ตามลำดับนี้จากความจำ รัน แล้วเรียก GET /health ให้ได้ {"status":"ok"} ก่อนไปต่อ

เรื่องใหม่วันนี้

Route ที่มีตัวแปร

/evaluatees/:id แปลว่าส่วนท้าย URL เป็นอะไรก็ได้ แล้วเราอ่านค่าได้จาก req.params.id ค่าที่ได้เป็นข้อความเสมอ เช่น "2" ไม่ใช่ตัวเลข 2

ข้อมูลที่ส่งมากับ POST

ข้อมูล JSON ที่ส่งมาอยู่ใน req.body แต่ Express จะอ่านให้ก็ต่อเมื่อมี app.use(express.json()) อยู่ด้านบน

Status code ที่ใช้วันนี้

Codeความหมายใช้เมื่อ
200OKส่งข้อมูลที่ขอกลับไปได้
201Createdสร้างข้อมูลใหม่สำเร็จ
404Not Foundหาข้อมูลตาม id ไม่เจอ

ทำตามทีละขั้น

ทำเสร็จหนึ่งขั้น ทดสอบใน Thunder Client ให้ผ่านก่อน แล้วค่อยไปขั้นถัดไป อย่าพิมพ์ครบแล้วค่อยรัน

1

เตรียม Array และให้ Express อ่าน JSON ได้

เพิ่มต่อจาก const app = express();

app.use(express.json());

let evaluatees = [
  { id: 1, name: 'สมชาย ใจดี', department: 'IT' }
];
let nextId = 2;

ผ่านเมื่อ รันเซิร์ฟเวอร์ใหม่แล้วไม่มี error และ /health ยังใช้ได้

2

ดูรายชื่อทั้งหมด

app.get('/evaluatees', (req, res) => {
  res.json(evaluatees);
});

ผ่านเมื่อ GET /evaluatees ได้ Array ที่มีสมชายหนึ่งคน

3

ค้นทีละคนด้วย id

app.get('/evaluatees/:id', (req, res) => {
  const id = Number(req.params.id);
  const found = evaluatees.find(e => e.id === id);
  if (!found) {
    return res.status(404).json({ message: 'ไม่พบผู้รับการประเมิน' });
  }
  res.json(found);
});

ผ่านเมื่อ GET /evaluatees/1 ได้สมชาย และ GET /evaluatees/999 ได้ 404 พร้อมข้อความ

4

เพิ่มคนใหม่

app.post('/evaluatees', (req, res) => {
  const { name, department } = req.body;
  const newOne = { id: nextId++, name, department };
  evaluatees.push(newOne);
  res.status(201).json(newOne);
});

ใน Thunder Client เลือก Method เป็น POST แท็บ Body เลือก JSON แล้วใส่ข้อมูลแบบในตัวอย่างด้านบนสุด

ผ่านเมื่อ POST แล้วได้ 201 พร้อม id ใหม่ จากนั้น GET /evaluatees/2 เจอคนที่เพิ่งเพิ่ม

ติดตรงไหน เปิดคำใบ้ทีละชั้น

POST แล้ว error หรือ req.body ว่าง

Express รู้ได้ยังไงว่าข้อมูลที่ส่งมาเป็น JSON

คำใบ้ชั้นที่ 2

ดูบรรทัด app.use(...) ว่ามีหรือยัง และอยู่ก่อน Route ทั้งหมดหรือเปล่า

คำใบ้ชั้นที่ 3

ใน Thunder Client เช็กว่าแท็บ Body เลือก JSON ไม่ใช่ Text หรือ Form

มีข้อมูลอยู่ แต่ค้นด้วย id แล้วได้ 404

ลองใส่ console.log(typeof req.params.id) ใน Route แล้วดูผลใน terminal

คำใบ้ชั้นที่ 2

"1" === 1 ได้ผลเป็นอะไร

คำใบ้ชั้นที่ 3

แปลงด้วย Number(req.params.id) ก่อนนำไปเทียบ

รันแล้วขึ้นว่า port 3000 ถูกใช้อยู่

มีเซิร์ฟเวอร์ตัวเก่ารันค้างอยู่ หา terminal ที่รันอยู่แล้วกด Ctrl+C ก่อนรันใหม่

แก้โค้ดแล้วผลไม่เปลี่ยน

เซิร์ฟเวอร์ต้องรันใหม่ทุกครั้งที่แก้โค้ด หยุดด้วย Ctrl+C แล้วรันอีกรอบ

โจทย์ทำเอง: ตัวชี้วัด

สร้างข้อมูลชุดใหม่ชื่อ indicators ในไฟล์เดิม โดยปิดโค้ดตัวอย่างด้านบน เปิดดูได้เมื่อติดเกิน 10 นาทีเท่านั้น

ตัวชี้วัดหนึ่งตัวมี id, title (ชื่อตัวชี้วัด) และ weight (น้ำหนักคะแนน)

MethodEndpointต้องได้
GET/indicators200 พร้อม Array ทั้งหมด
GET/indicators/:id200 ถ้าเจอ, 404 ถ้าไม่เจอ
POST/indicators201 พร้อมข้อมูลที่สร้าง

ท้าทายเพิ่ม ถ้า POST มาโดยไม่มี title ให้ตอบ 400 พร้อมข้อความบอกว่าขาดอะไร

ติดเกิน 10 นาที ถามคู่ซ้อมก่อน คู่ซ้อมช่วยชี้ได้ แต่ห้ามพิมพ์แทน ถ้ายังไม่ออกค่อยเรียกจารย์
