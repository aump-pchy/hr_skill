ปิดเซิร์ฟเวอร์แล้วข้อมูลยังอยู่

เมื่อวานข้อมูลหายทุกครั้งที่หยุดเซิร์ฟเวอร์ วันนี้ย้ายข้อมูลจาก Array ลง MySQL ที่รันบน Docker แล้วส่งโค้ดขึ้น GitLab เป็นครั้งแรก

หยุดเซิร์ฟเวอร์ รันใหม่ แล้วส่ง
GET /evaluatees/2
ยังได้คนเดิม เพราะมาจากฐานข้อมูล
200 OK
{
  "id": 2,
  "name": "วิภา ตั้งใจ",
  "department": "บัญชี"

  7. 40 นาทีทายผล แล้วสลับคู่ตรวจ Exit Ticket

วันนี้เราจะเก็บโครง Route แบบนี้ไว้ทั้งหมด เปลี่ยนแค่ส่วนที่ค้นและเก็บข้อมูลจาก Array เป็นคำสั่ง SQL

เรื่องใหม่วันนี้

เส้นทางของข้อมูล

Thunder Clientส่งExpressเรียกผ่าน mysql2MySQL ใน Dockerตอบกลับทางเดิม

Express ไม่ได้เก็บข้อมูลเองแล้ว แค่ส่งคำสั่ง SQL ไปให้ MySQL แล้วรอผลกลับมา

Docker container

เหมือนกล่องที่มี MySQL ติดตั้งพร้อมใช้อยู่ข้างใน สั่งเปิด ปิด หรือลบได้ โดยไม่ต้องลง MySQL ลงเครื่องตรง ๆ ข้อมูลอยู่ในกล่องตราบที่ยังไม่ลบกล่อง

async และ await

การคุยกับฐานข้อมูลต้องรอผล Route ที่เรียกฐานข้อมูลต้องมี async ข้างหน้า และใส่ await หน้าคำสั่งที่ต้องรอ ถ้าลืม await จะได้ของที่ยังไม่เสร็จกลับมาแทนข้อมูล

Git และ GitLab

Git จดประวัติโค้ดในเครื่องเรา GitLab เป็นที่เก็บโค้ดกลางให้ทั้งทีมดึงไปใช้ วันแข่งต้องใช้ GitLab Server ทุกคนจึงต้องฝึกตั้งแต่วันนี้

ทำตามทีละขั้น

ทำเสร็จหนึ่งขั้น ตรวจให้ผ่านก่อนแล้วค่อยไปขั้นถัดไป

1

เปิด MySQL ใน Docker

เปิด Docker Desktop ให้ทำงานก่อน แล้วรันใน terminal

docker run --name ltc-mysql -e MYSQL_ROOT_PASSWORD=root1234 -e MYSQL_DATABASE=evaluation -p 3306:3306 -d mysql:8.4

ครั้งแรกจะดาวน์โหลดนานหน่อย รอจนเสร็จแล้วเช็กด้วย docker ps

ผ่านเมื่อ docker ps เห็น ltc-mysql และคอลัมน์ STATUS ขึ้นว่า Up

2

สร้างตารางและใส่ข้อมูลแรก

เข้าไปพิมพ์คำสั่งใน MySQL (รหัสผ่านคือ root1234)

docker exec -it ltc-mysql mysql -uroot -p --default-character-set=utf8mb4 evaluation

แล้ววางคำสั่ง SQL นี้

CREATE TABLE evaluatees (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  department VARCHAR(100)
);

INSERT INTO evaluatees (name, department) VALUES ('สมชาย ใจดี', 'IT');

SELECT * FROM evaluatees;

ผ่านเมื่อ SELECT แล้วเห็นสมชายหนึ่งแถว ภาษาไทยไม่เป็นเครื่องหมายคำถาม พิมพ์ exit เพื่อออก

3

ต่อ Express เข้ากับฐานข้อมูล

ติดตั้งตัวเชื่อมต่อในโฟลเดอร์โปรเจกต์

npm install mysql2

สร้างไฟล์ใหม่ชื่อ db.js ไว้ข้างไฟล์เซิร์ฟเวอร์

const mysql = require('mysql2/promise');

const pool = mysql.createPool({
  host: 'localhost',
  port: 3306,
  user: 'root',
  password: 'root1234',
  database: 'evaluation'
});

module.exports = pool;

ในไฟล์เซิร์ฟเวอร์ เพิ่มบรรทัดนี้ใต้ const app = express(); แล้วลบ let evaluatees = [...] กับ let nextId ทิ้ง

const pool = require('./db');

ผ่านเมื่อ รันเซิร์ฟเวอร์ได้โดยไม่มี error และ /health ยังใช้ได้

4

เปลี่ยน Route ให้อ่านเขียนจากฐานข้อมูล

แทนที่ Route เดิมทั้งสามตัวด้วยชุดนี้ สังเกตว่าโครงเหมือนเมื่อวาน เปลี่ยนแค่ตรงกลาง

app.get('/evaluatees', async (req, res) => {
  try {
    const [rows] = await pool.query('SELECT * FROM evaluatees');
    res.json(rows);
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

app.get('/evaluatees/:id', async (req, res) => {
  try {
    const [rows] = await pool.query(
      'SELECT * FROM evaluatees WHERE id = ?',
      [req.params.id]
    );
    if (rows.length === 0) {
      return res.status(404).json({ message: 'ไม่พบผู้รับการประเมิน' });
    }
    res.json(rows[0]);
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

app.post('/evaluatees', async (req, res) => {
  try {
    const { name, department } = req.body;
    const [result] = await pool.query(
      'INSERT INTO evaluatees (name, department) VALUES (?, ?)',
      [name, department]
    );
    res.status(201).json({ id: result.insertId, name, department });
  } catch (err) {
    console.error(err);
    res.status(500).json({ message: 'เกิดข้อผิดพลาดที่ฐานข้อมูล' });
  }
});

เครื่องหมาย ? คือช่องว่างที่ mysql2 จะเติมค่าจาก Array ให้อย่างปลอดภัย ห้ามเอาค่าที่ผู้ใช้ส่งมาต่อเป็นข้อความ SQL เอง

ผ่านเมื่อ POST คนใหม่ได้ 201 แล้วหยุดเซิร์ฟเวอร์ รันใหม่ GET ด้วย id นั้นยังเจอ และ GET id 999 ได้ 404

5

ส่งโค้ดขึ้น GitLab

สร้างไฟล์ .gitignore ในโฟลเดอร์โปรเจกต์ ใส่บรรทัดเดียว

node_modules

ถ้าเครื่องนี้ยังไม่เคยใช้ Git ให้ตั้งชื่อก่อนครั้งเดียว

git config --global user.name "ชื่อของเรา"
git config --global user.email "อีเมลของเรา"

สร้าง project เปล่าบน GitLab ตามที่จารย์บอก คัดลอก URL ของ project มา แล้วรัน

git init
git add .
git commit -m "เก็บข้อมูลผู้รับการประเมินลง MySQL"
git branch -M main
git remote add origin URL_ของ_PROJECT
git push -u origin main

ผ่านเมื่อ เปิดหน้า project บน GitLab แล้วเห็นไฟล์ของเรา และไม่มีโฟลเดอร์ node_modules

ติดตรงไหน เปิดคำใบ้ทีละชั้น

Error ขึ้นว่า ECONNREFUSED

Express ต่อ MySQL ไม่ติด ลองดูว่า container ยังทำงานอยู่ไหม

คำใบ้ชั้นที่ 2

รัน docker ps ถ้าไม่เห็น ltc-mysql ให้ docker start ltc-mysql แล้วรอ 10–20 วินาทีให้ MySQL พร้อมก่อน

Error ขึ้นว่า ER_ACCESS_DENIED_ERROR

รหัสผ่านใน db.js ตรงกับตอนสั่ง docker run หรือเปล่า

Error ขึ้นว่าไม่มีตาราง evaluatees

ตารางถูกสร้างในฐานข้อมูลชื่อ evaluation จริงไหม

คำใบ้ชั้นที่ 2

เข้า MySQL อีกรอบแล้วพิมพ์ SHOW TABLES; ถ้าไม่เห็น ให้กลับไปทำขั้นที่ 2 ใหม่ และดูว่า database ใน db.js สะกดตรงกัน

docker run แล้วบอกว่า port 3306 ถูกใช้อยู่

เครื่องนี้มี MySQL อีกตัวรันอยู่แล้ว

คำใบ้ชั้นที่ 2

ลบ container ที่สร้างไม่สำเร็จด้วย docker rm ltc-mysql แล้วรันใหม่โดยเปลี่ยนเป็น -p 3307:3306 และแก้ port: 3307 ใน db.js

ได้ข้อมูลแปลก ๆ หรือ rows เป็น undefined

ดูว่ามี await หน้า pool.query หรือยัง และ Route มี async ข้างหน้าหรือเปล่า

คำใบ้ชั้นที่ 2

pool.query ส่งกลับมาเป็น Array สองช่อง ช่องแรกคือข้อมูล จึงต้องเขียน const [rows] = มีวงเล็บเหลี่ยม

ภาษาไทยในฐานข้อมูลเป็นเครื่องหมายคำถาม

ตอนเข้า MySQL ลืมใส่ --default-character-set=utf8mb4 ลบแถวนั้นแล้วเข้าใหม่พร้อมตัวเลือกนี้ ข้อมูลที่ POST ผ่าน Express จะไม่มีปัญหานี้

git push ถูกปฏิเสธหรือถามรหัสผ่าน

เรียกจารย์ เรื่องสิทธิ์เข้า GitLab แก้จากฝั่ง project

โจทย์ทำเอง: ย้ายตัวชี้วัดลงฐานข้อมูล

เอา /indicators ที่ทำเมื่อวานมาเปลี่ยนให้ใช้ฐานข้อมูล ปิดโค้ดตัวอย่างไว้ เปิดดูได้เมื่อติดเกิน 10 นาทีเท่านั้น

สร้างตาราง indicators มีคอลัมน์ id (เลขอัตโนมัติ), title (ข้อความ ห้ามว่าง) และ weight (ตัวเลข)

MethodEndpointต้องได้
GET/indicators200 พร้อมข้อมูลจากตาราง
GET/indicators/:id200 ถ้าเจอ, 404 ถ้าไม่เจอ
POST/indicators201 พร้อม id ที่ฐานข้อมูลสร้างให้

เสร็จแล้ว commit และ push ขึ้น GitLab อีกครั้ง

ท้าทายเพิ่ม ถ้า POST มาโดยไม่มี title ให้ตอบ 400 ก่อนส่งคำสั่งไปฐานข้อมูล

ติดเกิน 10 นาที ถามคู่ซ้อมก่อน คู่ซ้อมช่วยชี้ได้ แต่ห้ามพิมพ์แทน ถ้ายังไม่ออกค่อยเรียกจารย์

ทายผลก่อนกดส่ง
